# black

Android端末のChromeで使う、黒画面のカメラ録画ページです。

## 操作
- ダブルタップ：背面カメラで録画開始。全画面表示を要求します。
- トリプルタップ：録画終了。録画ファイルのダウンロードを開始します。
- 画面表示：常に黒色です。

## 動作条件・注意
- カメラ利用にはHTTPS接続と、ブラウザーでのカメラ許可が必要です。
- 初回のカメラ許可ダイアログはブラウザー／Androidが表示します。
- OSのカメラ使用インジケーターは消せません。
- 動画はブラウザーのダウンロード機能で端末に保存されます。Androidの設定によって保存先や確認方法が異なります。
- MP4形式のMediaRecorderに対応するブラウザーが必要です。対応していない場合は録画を開始しません。
- このページは画面上に録画状態を表示しません。利用者本人がカメラ許可と操作方法を確認して使用してください。
